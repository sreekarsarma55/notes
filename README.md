# 📚 Notes

A personal knowledge base for study notes, revision material, cheat sheets, and worked problems across different subjects.

## 🗂️ How this repo is organised

**One branch per subject.** Each subject lives on its own long-lived branch so material stays isolated and can grow independently. This `main` branch holds only this guide, the subject index, and repo-level configuration.

| Subject | Branch | Coverage |
|---------|--------|----------|
| Machine Learning Techniques (MLT) | [`mlt`](https://github.com/sreekarsarma55/notes/tree/mlt) | Weeks 1–12 |

> To add a new subject, create a new long-lived branch (e.g. `dsa`, `stats`, `dbms`) and follow the layout below.

## 🔀 Workflow

Topic/week work branches off the **subject branch** and merges back into it — not into `main`:

```text
                    ┌── mlt-week9 ──┐
subject branch  mlt ┤               ├──►  PR base = mlt
                    └── mlt-week10 ─┘
```

`main` only changes for repo-level things (this guide, `.gitignore`, steering).

## 📁 Layout within a subject branch

```text
<subject>/
├── README.md          # subject index + how to use these notes
├── NN-topic.md        # one file per topic/week, fully explained
├── cheat-sheet.md     # condensed one-page formula sheet for last-minute revision
├── mock-solutions.md  # worked solutions to mock/practice papers
└── images/
    ├── make_figures.py   # every figure is generated by this one script
    └── *.png
```

Regenerate all figures with:

```bash
python3 -m pip install matplotlib numpy
python3 images/make_figures.py
```

## ✍️ Conventions

- **Markdown** for all notes, with plain-text math blocks (renders everywhere, including GitHub and mobile).
- **Images only where they add understanding** — diagrams for intuition, not decoration.
- Each topic file follows the same shape: *intuition → formulas → worked example → common exam traps*.
- Formulas and worked examples are **numerically verified** before being committed.

Full contributor conventions live in [`.kiro/steering/notes-workflow.md`](.kiro/steering/notes-workflow.md).
